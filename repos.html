Local Environment Setup

Clone

Clone any repository to your local machine.

git clone https://github.com/Ishuin/<repo>.git
cd <repo>

Virtual Environment

Use Python venv or conda for Python projects.

python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

Node / Frontend

Install dependencies and run dev server.

npm install
npm run dev
